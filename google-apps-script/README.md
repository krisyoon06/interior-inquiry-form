# Google Sheets 연동 배포 방법

문의 폼(`inquiry.html`)에서 제출된 내용이 Google Sheets에 자동으로 쌓이도록 연동하는 절차입니다.

## 1. 스프레드시트 생성
1. Google Sheets에서 새 스프레드시트를 만듭니다. (예: "인테리어 상담 문의 내역")
2. 상단 메뉴에서 `확장 프로그램 > Apps Script`를 클릭합니다.

## 2. 스크립트 등록
1. 열린 Apps Script 편집기에서 기본 `Code.gs` 내용을 모두 지웁니다.
2. 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
3. `저장` (Ctrl/Cmd+S) 합니다.

## 3. 웹앱으로 배포
1. 우측 상단 `배포 > 새 배포`를 클릭합니다.
2. 유형 선택에서 톱니바퀴 아이콘을 눌러 `웹 앱`을 선택합니다.
3. 다음과 같이 설정합니다.
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (폼 제출자가 로그인 없이 전송해야 하므로)
4. `배포`를 클릭하고, 처음 배포 시 권한 승인(Google 계정 로그인 및 "안전하지 않음" 경고에서 계속 진행)을 완료합니다.
5. 배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/xxxxxxxx/exec` 형식)을 복사합니다.

## 4. 폼 페이지에 URL 연결
`inquiry.html` 하단 `<script>` 영역에서 아래 줄을 찾습니다.

```js
var SCRIPT_URL = 'https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec';
```

`YOUR_DEPLOYMENT_ID` 부분을 3번에서 복사한 실제 웹앱 URL로 교체합니다.

## 5. 동작 확인
1. `inquiry.html`을 브라우저로 열고 테스트 데이터를 입력해 제출합니다.
2. 연결한 스프레드시트에 `문의내역` 시트가 자동 생성되고, 제출한 행이 추가되는지 확인합니다.

## 참고
- 스크립트를 수정한 뒤에는 `배포 > 배포 관리 > 수정(연필 아이콘) > 새 버전`으로 다시 배포해야 변경사항이 반영됩니다.
- 폼은 `no-cors` 모드로 전송되어 브라우저에서 응답 성공 여부를 직접 확인할 수 없습니다. 실제 저장 여부는 스프레드시트에서 확인하세요.
- 문의 내역에는 개인정보(이름, 이메일, 연락처, 주소 등)가 포함되므로, 스프레드시트 공유 권한을 필요한 담당자로 제한하는 것을 권장합니다.
